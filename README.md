# PitWall

Real-time motorsport statistics hub. **Formula 1 at launch** — live timing, standings, results, and calendar — with F2, F3, Formula E, WEC, WRC, NASCAR, MotoGP, and GT on the roadmap.

**Stack:** Django 5 (templates + HTMX + Alpine.js + Bootstrap 5) · SSE live updates · Celery · PostgreSQL · Redis · Docker.

See [docs/BLUEPRINT.md](docs/BLUEPRINT.md) for the full product & technical blueprint.
